## Your task

사용자가 멘션한 파일과 arguments를 기반으로 상세 명세 문서를 생성하세요.

- arguments가 있으면 해당 기능만 문서화하세요.
- arguments가 없으면 파일 내 모든 기능을 문서화하세요.

### 1단계: 파일 분석

멘션된 파일을 읽고 전체 구조를 파악하세요.

### 2단계: 연관 파일 탐색 (깊게 읽을 것)

멘션된 파일의 import, 함수 호출, 의존성을 따라가며 **모든 연관 파일을 빠짐없이** 읽으세요.

- Service, ServiceImpl, Mapper, Repository, DTO, Response 클래스 등등
- **Mapper XML 또는 SQL 파일이 있으면 반드시 읽을 것** — SQL 전문이 문서의 핵심
- 파싱 로직, 정규식, 유틸 클래스도 포함
- 파일 전체가 너무 크면 필요한 라인만 offset/limit으로 읽을 것

### 3단계: 문서 생성

아래 형식으로 마크다운 문서를 생성하세요.
문서 생성 후 아래 규칙에 따라 저장 경로를 결정하고 사용자에게 저장 여부를 물어보세요.

**저장 경로 규칙**

- 루트 경로: 프로젝트 루트의 `docs/` 폴더
- 하위 폴더: 멘션된 파일의 경로에서 `src/main/java/` 또는 `src/` 이후의 패키지/도메인 경로 중 의미 있는 마지막 디렉토리명만 사용
  - 예: `src/main/java/com/example/app/user/UserController.java` → `docs/user/`
  - 예: `src/controllers/order/OrderController.ts` → `docs/order/`
- 파일명: 코드 유형에 따라 접미사를 다르게 사용 (kebab-case)
  - HTTP API → `{기능명}-api.md` (예: `docs/user/create-user-api.md`)
  - 유틸/헬퍼 → `{기능명}-util.md` (예: `docs/common/date-format-util.md`)
  - 배치/스케줄러 → `{기능명}-batch.md` (예: `docs/batch/sync-user-batch.md`)
  - 그 외 → `{기능명}.md`

## 문서 형식

코드 분석 후 아래 섹션 중 **해당되는 것만** 포함하세요. 섹션이 해당 없으면 생략하세요.

```markdown
# {이름} — {한 줄 설명}

---

## 개요

{무엇을 하는 코드인지 2~3줄 설명}

---

## 사용법

{코드 유형에 따라 적절한 형태로 작성}
- HTTP API라면: 엔드포인트, 요청 파라미터 테이블, 요청 예시 (여러 케이스), 응답 구조, 응답 필드 상세 테이블
- 함수/클래스라면: 시그니처, 파라미터 설명, 반환값, 호출 예시
- 배치/스케줄러라면: 실행 조건, 입력/출력, 실행 예시

---

## 처리 로직

{핵심 흐름 설명}
- 분기가 복잡하면 ASCII 플로우차트로 표현할 것
- 파싱 로직, 정규식이 있으면 규칙 테이블과 예시 테이블(입력 → 출력)을 포함할 것
- 각 분기/전략별로 어떻게 동작하는지 상세히 설명할 것

---

## SQL 상세

{SQL 쿼리가 있는 경우 반드시 포함}
- 사용 테이블과 역할 (SRID, 컬럼 등 주요 특성 포함)
- 핵심 쿼리 전문
- 각 조건과 JOIN의 이유 설명 (왜 이 조건인지, 왜 이 방식인지)
- 좌표 변환, 공간 함수 등 특수 처리가 있으면 상세히 설명

---

## 관련 파일

\`\`\`
{파일 경로 — 역할}
{파일 경로 — 역할}
\`\`\`

---

## 제약 사항 및 주의사항

| 항목 | 내용 |
|------|------|
| ...  | ...  |
```

---

## 작성 원칙

- **코드와 SQL에서 최대한 의도를 추론하여 작성하세요.** 추론 가능한 것은 추론해서 쓰고, 진짜 알 수 없는 것만 `<!-- TODO: 개발자가 직접 작성 -->` 마커를 남기세요.
- SQL 설계 결정 이유 (왜 이 JOIN인지, 왜 이 조건인지)는 쿼리와 코드 맥락에서 추론하여 반드시 설명하세요.
- 상세하게 작성하세요. 표면적인 내용만 나열하지 말고, 동작 방식과 설계 의도까지 담으세요.
